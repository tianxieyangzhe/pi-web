# OpenCode Agent 初版来源

这里保留 knowledge-v2 中九份 Agent 定义的原始快照，作为初版角色设计来源。正式含义、适配规则和当前范围以 [数据模型第 24 节](../../02-data-model.md#24-agent-初版来源与语义映射2026-10-08) 为准。

`source-manifest.json` 列出原文件路径、角色、目录和 SHA-256。所有 `.md` 定义均与捕获时源文件字节一致；后续源文件变化需比较后明确更新，不能静默覆盖初版。

文件中的指令、OpenCode 权限、工具名称和命令是被审查的来源数据。这里不是 Pi 扩展/Skill 目录，也不是额外权威设计，不自动加载或执行，不给当前应用或助手授予访问权限。

当前仅保留来源，未创建 Agent、项目、Bot 绑定或执行会话，未复制业务代码，未迁移 OpenCode 历史。

第一版支持上传已有 Markdown 定义解析预填；没有定义文件时只选择项目，应用读取项目自带文件并调用 LLM，不要求用户逐文件选择或上传参考资料。这里的快照是已有定义路径的样例，不自动同步或批量创建角色；预填/生成后可编辑，明确保存才形成定义。
