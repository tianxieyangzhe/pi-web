## 6. 会话树：标题与正文定位

## 8. 文件弹窗

文件浏览与文件预览属于同一个非模态浮动窗口。宽屏内部为目录树与预览两区，窄屏在弹窗内切换浏览/预览，不打开第二个抽屉或单独的预览列。文件树来自所属范围的文件列表 API，非 Git 仓库也能浏览；Git 状态为可选附加信息，失败不遮蔽文件列表。项目根目录按钮、根路径与子目录路径保留，长路径可横向滚动。

本地源码链接调用所属 API 后打开该弹窗，自动选择文件并滚动、高亮目标行；项目路径边界与工作区项目定位见各自 API。预览只读，代码使用浅灰绿底与深灰字。空目录、加载、读取失败、目录截断、二进制和超限均明确展示。敏感路径、越界、符号链接和大小校验仍由服务端完成。外部链接保持原行为，选择变化后的旧响应不能覆盖新文件。

## 9. 左侧动作与会话切换

左侧整个区域的任何单击（包括空白、文字及按钮）的动作开始前，统一关闭现有文件、会话检查及其附属浮层，也关闭已有项目资料、会话创建等临时弹窗，再执行目标动作；目标动作需要弹窗时打开它自己的新弹窗。覆盖展开/收起、项目/工作区选择、新建、删除、角色/MCP/设置及导航收缩；点击当前已选会话也执行关闭。实际会话身份变化（含其他入口与程序化导航）同样触发，不能只监听某一个会话行按钮。

关闭统一清理未提交表单草稿、取消本地读取或忽略迟到响应，不让旧请求重新打开弹窗或覆盖新会话。同一 Session 的树浏览选择保留，仅用于再次定位与树浏览，不提供从节点创建会话入口；树正文定位可在关闭后完成，左侧导航或会话切换时清除该目标与选择。已接受的模型切换和压缩不因关闭而取消；停止与取消压缩必须调用对应 API。未提交的设置选择丢弃，主 Composer 草稿及主请求生命周期按原契约处理。

通用动作按 03 §11～15 的完整契约投影，状态与验收计划见05 §15；GAP-006及工作区专属缺项本轮保留。没有 Session 时会话检查禁用并给出原因；没有可浏览项目时文件入口按所属 API 能力禁用。两种会话同步采用以上投影，工作区专属映射见 06。本轮状态见 05，文档完成不代表弹窗、模型切换、派生和导出已经实现。

两类会话的Session设置展示GET assistant的当前精确版本及选择/移除入口，调用PUT assistant；独立项目只展示project级，Workspace展示project级及适配本工作区的workspace级。等待/错误来自API，不修改运行中配置。

## BUTTON-001｜全应用按钮规范

覆盖项目/工作区设置与导航、助手列表和编辑、会话输入与检查、文件和目录选择、模态与浮窗、错误重试及上传触发器。React按钮只能由 `web/components/button.tsx` 的Button渲染；必须保留原type、许可、事件、ARIA、表单提交和取消行为。contentEditable内由原生DOM创建的附件删除按钮、上传label等触发器复用同模块buttonStyles；附件按钮的disabled映射已有编辑许可，不在编辑DOM引入独立React根。

- 统一字体12px、行高20px、常规字重、8px圆角、1px边框，无阴影和悬浮位移；直接图标统一14px。
- 标准操作按钮高32px，横向12px内边距；纯图标按钮为32×32px，有可访问名称；Composer发送按钮使用共享iconCompact尺寸24×24px，停止按钮保留标准尺寸。侧栏双行会话使用共享session尺寸，固定32px高、无纵向内边距，标题与时间字号及行高按NAV-002。导航、树与文件选择使用同规范的行按钮：最小高32px，长内容允许增高、左对齐；语义布局可伸展，不以逐页定制改变字号和视觉。
- secondary：白底、slate-200边框、slate-600文字；primary：emerald-700底与边框、白字；danger：白底、red-200边框、red-700文字；ghost：透明底及边框，供导航/图标操作。选中状态统一为浅绿底与绿色文字、边框，primary选中保持其绿色底与白字。tab为选项卡专用变体，保持32px高度与共享键盘焦点，透明背景、零圆角、仅2px底边；未选中灰字和透明底边，选中绿色文字与绿色底边，不使用操作按钮的框和选中底色。
- 悬浮仅改变颜色，disabled不能出现悬浮响应，统一降低透明度与不可操作光标；键盘focus-visible统一2px emerald-600轮廓、2px外偏移。加载沿用原操作许可，图标不改变按钮尺寸。
- 页面只选择语义variant和size，className仅表达位置、排列及内容溢出。禁止自行声明按钮字体、背景、边框、圆角、内边距、高度和聚焦样式；不得新增裸button绕过共用入口。旧全局按钮外观规则删除或退役，避免级联重新引入不一致。
