# 04｜页面：API 投影

本文范围：独立项目与通用页面投影。Bot 的全部专属设计、模型、API、交互与需求统一见 [06｜Bot](06-bot.md)，本文不定义或复写其规则。

本文不是功能定义。功能只有模型和 API 两个要点；本文只记录页面如何投影 API 返回的模型、派生状态和所属 Pi transcript。

每个区域写明层级、信息来源、空/忙/错状态、响应式行为，以及用户动作对应的 API、等待反馈、成功更新和失败后保留的草稿。页面不定义新字段、新状态或新接口。

组件选择遵循 `01` 的 AI Elements 规则。没有合适官方组件时，先登记例外，再实现替代。

## 当前规则

## 1. 产品术语与页面分层
| 内部对象 | 页面名称 | 用户看到的作用 |
| --- | --- | --- |
| Project | 项目 | 文件与执行资源边界 |
| Session | 项目会话 | 可复用 Pi 上下文，多任务/多次工作共享原会话历史 |
| SessionMemory | 记忆 | Session 自动总结和人工干预的辅助工作线 |
| 无SessionMemory | SessionMemory 模板 | 可复制的初始上下文 |
| 其他资源模板/项目实例 | 模板库 / 项目资源 | 在 Project 内复制、配置与单独调试 |

前端保持 `Route → View → Feature Wrapper → AI Elements/基础组件` 分层。状态、同源 API 与 NDJSON 解析分别放在 Hook/API Client 中，页面 JSX 只装配可读区域。

## 2. 顶层导航与创建
~~~text
/
├─ 快捷操作：新建项目会话 / 记忆模板库
├─ Project [＋ 新建项目]
│  └─ Project A
│     ├─ 点击项目行：进入最近项目会话并切换记录树展开状态
│     ├─ 展开箭头：只切换记录树
│     └─ 项目会话：可选项目角色和空 SessionMemory/记忆模板
│     └─ 独立 Session 记录：显示当前生效记忆摘要；独立空会话显示“新会话”；单击后进入该 Project Session，收起右侧面板、文件预览及所有浮窗
└─ 角色 / MCP / Settings
~~~

Agent 导航入口位于侧栏底部，产品文案为“角色”，显示规则见“独立项目 Agent 列表与编辑工作区”。MCP 入口只管理资源；模板不能直接执行，复制后的配置和调试属于目标 Project。角色定义与版本引用按 `02`“独立项目 Agent Markdown”。

创建独立项目会话的弹窗仍显示 Project、可选的同项目角色、空 SessionMemory/模板选择与模板内容预览；不选角色也可创建并直接发送。角色入口联动见“独立项目 Agent 列表与编辑工作区”。复制记忆模板只初始化新会话的指导线展示，不建立草稿、不影响主 Pi 请求。Project 新建/编辑和删除确认继续使用弹窗，不占用右侧检查列。

## 3. 主画布与列
桌面默认布局：

~~~text
Project Navigation | 当前项目对话 | Context Panel（按需）
~~~


Project 导航使用低亮度浅灰蓝背景，不出现“AI Workspace”顶部品牌栏，不使用深蓝背景或蓝色正文。项目、会话和操作文字采用中性灰黑；选中项使用柔和浅绿色背景和标记。蓝色只用于克制的焦点、图标和主要操作。主画布避免大面积刺眼纯白或高饱和浅蓝。

## 4. Session 对话
~~~text
ProjectSessionPage
├─ Header：Project / 当前 Session / 导航与 Context Panel 开关
├─ Conversation
│  └─ 所属 Pi Session Tree 的全部节点与分支（对话流投影）
├─ SessionMemory 状态入口：指导线内容 / 同步状态
└─ Composer
~~~

选中会话时通过 `03` 的打开 API 建立或恢复对应 Pi Session，等待成功后展示其完整 Session Tree，标识活动分支；打开失败显示 API 错误和重试入口，不允许对未打开会话发送。切换立即展示新选择，不等待旧会话运行；再次打开旧会话时按 API 返回的运行状态和历史恢复展示，超时中止或状态未知时显示 API 返回的结果，不将其标记为成功。页面关闭、刷新或断线时的使用权和超时由 `03` 规定，页面不自行推断执行结果。

用户参考 `custom_message` 按 `03` 的确定父子关系归组时，显示在对应用户正文下方的“本轮附件”折叠区，保留完整原文、图片预览和原始节点；不再在正文前方重复占位。无法归组仍独立展示。参考消息实时阶段显示“本轮附件 · 同步中”，可靠关联后由原生节点接替，不在末尾残留 custom 的临时标头。

项目会话均按 `03` 将所属 Pi Session Tree 全部节点投影为对话流，按 API 返回的原生追加顺序展示，并通过父子关系标明分叉和活动路径；父节点缺失或自引用的节点标明异常、仍可查看，共享祖先只显示一次，不将不同分支伪装为连续上下文。内部节点、thinking、工具参数和完整结果、压缩、custom 及其他节点都可查看，不因敏感内容或原生 display 标记过滤；节点可折叠，但展开后保留完整内容。实时事件与历史节点的关联和重读以 `03` 为准；项目只读、发起与非发起页面均按 `03` 订阅所属 Session 的实时变化；首次打开和重连核对快照，不定时轮询历史。读取失败保留现有内容并显示错误。Assistant 回复使用安全 Markdown，支持加粗内的链接及链接文字内的行内代码等嵌套行内格式；原始 HTML 不执行，嵌套链接也需校验协议，链接文字不再生成嵌套锚点；安全渲染不删改正文。代码围栏和列表按原始 Markdown 展示，不将无标记的普通文字猜测为代码或列表。定向验证 tests/markdown-response.test.cjs 两项通过，覆盖 LCA 回复的加粗文件链接/行内代码、Go 围栏、列表，以及危险链接拒绝与 HTML 惰性展示；类型检查与差异检查通过，浏览器视觉未验收。


项目会话 Composer 的输入框下方紧邻并排提供“上传文件”和“参考项目文件”两个入口，已选文件、图片及折叠文本以内联不可编辑块插入输入区当前光标/选区位置，不在工具栏下方另列附件。打开上传或目录弹窗前保存选区，选择后插入该位置；无有效选区时回退输入区末尾。候选块为不可拆分的独立单位，块前后均提供可落点的编辑边界；左右方向键跨过整个块，Backspace/Delete 在边界删除整个块，选区替换同步移除对应发送材料。插入完成后光标自动落在最后一个新块后方，点击块本体也落在块后，移除按钮只删除该块；边界占位字符不进入草稿正文或消息 API。文件名不撑开输入区。发送后的用户消息不额外标注文件；Pi 树中的参考关联节点仍按会话树投影展示，PNG/JPEG/GIF/WebP 内容块支持折叠图片预览，完整原始图片节点仍可展开查看。上传打开系统文件选择器，不关联项目；参考打开视口居中的可关闭模态对话框，项目会话展示所属项目；逐级浏览目录、多选文件，不提供路径输入。两类选择均可移除，随消息提交；接受前失败保留输入和选择并显示错误。项目会话无可用项目时禁用参考入口。

项目会话提交后运行期间，在本地回显下显示带转圈的“正在思考”，直到本轮首次展示文本、thinking 或工具活动，或执行结束、失败。这是等待响应提示，不是模型 thinking 内容或 transcript entry。

Composer 支持粘贴图片为可移除的缩略图附件；超过 10 行或 1000 字符的粘贴文本不铺开，只显示“已粘贴 N 行”及移除按钮。其他文本沿用原生粘贴；粘贴材料与上传文件共同计数并受同一限制，失败用气泡提示并保留原输入。仅附件也允许发送，完整内容沿用 references 契约进入所属 Pi。

Composer 支持 Enter 发送、Shift+Enter 换行；发送按钮仍可直接提交。IME 候选组合期间按 Enter 只确认候选、不提交；判断同时使用 composition 事件状态、`nativeEvent.isComposing` 和旧浏览器 `keyCode=229` 兼容标记。运行时发送/停止处于同一操作组。项目 Session 在排队、启动和运行阶段均可停止；提交停止后显示“正在停止”，保持执行门禁直到 Runtime 确认结束。结果 unknown 时不提供会伪装取消的停止按钮，显示待核对状态和准确恢复入口。Composer 不提供模型、Runtime、工具、Agent、MCP 或 Skill 的配置控件。

### 紧凑 Tailwind 对话流

会话主体用 Tailwind `px-3 py-3 sm:px-4`，tree 节点之间固定间距 `gap-1`（4px），普通节点不额外设置纵向 padding；消息内部 thinking、工具调用与正文块也统一使用 4px 间距，折叠展开区仅顶部留 4px、底部不加 padding，用户消息 `px-3 py-2`，assistant 正文不套多层厚卡片。消息身份和正文间距 `gap-1`；不设消息最小高度，短消息自然撑开，正文使用可用宽度。Markdown 段落、标题和列表保持紧凑间距与可读行高。标题栏采用 `px-3 py-3 sm:px-4` 且不设最小高度，Composer 外层 `px-3 py-2 sm:px-4`；输入正文占满宽度，`px-3 py-2`、初始及最小高度 112px，可纵向拖动至视口高度的 40%（上限不低于 112px）。上传、参考文件与发送/停止合并为同一紧凑底栏，快捷键提示以底栏小字常驻展示，与工具、发送按钮共用一行，不单独增加提示栏高度；运行及禁用原因在同一位置替换快捷键提示。附件以内联块出现在输入区，不设独立附件行或下方 padding；工具入口、提示及发送操作仍共用紧凑底栏。会话连接、发送及上传校验的报错使用右下角气泡通知，不占用输入框或对话流空间；气泡完整展示错误、允许手动关闭，有既定重试动作时保留重试按钮，不自动消失或改变执行状态。文件浏览弹窗内的读取错误仍在弹窗内展示。底部操作行不设固定最小高度。正文显示文字和安全 Markdown，thinking、工具调用及结果就地展开；不展示额外的“节点信息”组件、角色标头或详情入口。消息正文直接展示；model_change 等非消息节点仅使用原有“原生节点 · 类型”折叠面板，展开显示完整原始 entry。原生节点、thinking、工具调用和完整工具结果共用同一折叠样式：折叠标题为 10px 灰色文字，无边框、底色或卡片 padding，展开内容仅顶部留 4px 间距、底部不加 padding；thinking 与原始参数/节点使用紧凑 10px 行高 16px，原始内容无额外背景和 padding，完整工具结果展开后同样使用通用 Raw 展示完整消息对象，采用 10px 等宽灰字、16px 行高，无底色或额外 padding，不再套用正文 Markdown 排版。实时工具与事件也复用该样式。节点身份与父子关系保留在原始内容中。未知块、内部节点和异常节点仍可查看，不以 JSON 代替普通对话正文。分支信息用轻量标记表达，全树按原生追加顺序展示，共享节点只展示一次。订阅连接的等待、断线和错误独立于运行成功/失败；页面收到服务器 ping 后应答，不自行定时保活。

## 5. 固定指导线展示
记忆以工作概况、目标、项目约束、重要事实、决策、下一步、产出七个固定部分展示，含义以 `02`“SessionMemory 当前上下文”为准。面板保留名称“记忆”；顶部立即总结和同步状态保留，每部分正文旁小号“修改”打开富文本局部编辑。总结及人工修改只更新展示，不显示“用于下一条对话”或“已生效提示词”等标签。

## 6. 总结与校正反馈
每次完整回答后独立增量总结并直接展示；等待、错误、未知同步状态如实呈现。人工保存刷新原栏位及侧栏摘要，弹窗提示“仅修改总结展示；其他部分不变”。取消/关闭丢弃未保存修改并中止客户端请求，不操作主会话 Runtime。

## 7. 文件与检查
项目文件树从独立文件列表 API 加载，即使 Project 不是 Git 仓库也能浏览和预览。根目录按钮标为“项目根目录”，路径栏显示 Project.rootPath 与当前子目录组成的绝对路径，长路径允许横向滚动。Git 状态与变更为可选附加信息，失败时不得替代或隐藏文件列表。

文件预览只读，代码区域使用柔和浅灰绿底和深灰文字，不使用黑色背景。空目录、加载中、读取失败、目录截断和二进制/超限文件有明确状态。服务端执行路径越界、敏感段、符号链接和大小检查。SessionMemory 产出中的相对路径链接只有经同一安全校验后才可打开预览。

检查面板展示当前 Session 状态、Pi Runtime 恢复诊断、真实工具活动和项目资源的安全摘要；不显示 secret、原生 transcript 文件路径、Runtime 句柄或完整内部 system prompt。

## 8. 响应式、空状态与可访问性
| 场景 | 页面表现 | 可用操作 |
| --- | --- | --- |
| 没有 Project | 项目欢迎页 | 新建项目 |
| Project 没有 Session | 项目空状态 | 创建会话与空 SessionMemory，或选 SessionMemory 模板 |
| LLM 总结中或失败 | 独立进度/错误，不遮挡对话 | 继续对话、重试 |
| Session unavailable | 保留 transcript 与 SessionMemory 内容 | 恢复或诊断 |
| Project 被停用 | 历史内容只读 | 管理 Project |


## 9. 本版 UI 不包含
- Session 对话中展示 SessionMemory 自动总结作为 Pi 原始思考；
- SessionMemory context 文件或原生 JSONL 文件入口；会话树节点中的原始内容按 `03` 展示；
- SessionMemory 内的工具、扩展、Agent、MCP、Skill 编辑入口；
- 用户可见的 SessionMemory 内容版本系统。

## 10. SessionMemory 面板操作细节
~~~text
记忆                     [立即总结] [关闭]

与已完成对话同步 · 更新时间
  工作概况                         修改
  目标 / 约束 / 事实 / 决策 / 下一步   各自修改
  产出摘要                         修改 / 安全文件链接
~~~

仅展示已保存的当前记忆及同步状态，不展示候选差异、草稿审核或确认入口。状态与恢复依据见 `03`“API 响应、状态与恢复”。

当前内容不设统一“编辑”按钮。七个栏位正文旁各有小号“修改”文字操作，无边框、底色和按钮留白，空值时与“尚未填写”并排显示；已填写时仍在内容区域提供同样入口。文字操作保留键盘可达性和清晰焦点。点击后用模态弹窗修改该部分，原面板保持展示。弹窗提供加粗、斜体、段落和列表的富文本编辑；数组支持逐条新增、删除和排序，产出保留标题与安全相对路径输入。富文本转换为安全 Markdown 字符串，不存 HTML、不增字段，容量与路径约束仍以 `02` 为准。局部修改基于打开弹窗时的完整上下文快照和 writeETag，只替换选中字段后条件保存；冲突不盲合并。弹窗固定最大高度，编辑区超长滚动。


## 11. 冲突、生成和恢复反馈
| 状态 | 页面说明 | 操作 |
| --- | --- | --- |
| queued / generating | “等待当前对话结束” / “正在整理会话上下文” | 继续对话；生成中不显示假的百分比 |
| 表单写入冲突 | “内容已更新，你的修改尚未保存” | 保留本地输入、加载最新内容对照、重新编辑提交 |
| 生成失败 | 安全错误及重试提示，当前生效内容仍可用 | 重试 |
| 来源过长 | “本次对话超过总结上限，未跳过来源” | 继续对话、手动维护当前内容、重试；不伪装已总结 |
| 来源不可用 | “无法读取对话来源，自动总结暂停” | 主 Session 恢复/诊断；当前内容仍可人工维护 |
| 数据损坏 / 旧库不兼容 | 明确损坏或兼容诊断 | 诊断入口；不能以空内容显示或继续关联写入 |


## 12. “立即总结”按钮与计数反馈
“立即总结”位于右侧面板最上方标题栏、关闭按钮左侧。内容区不重复显示记忆标题，不显示生效说明、自动触发规则或回答计数说明；只显示必要的生成状态、错误和操作结果。触发规则与计数仍以 `03`“每次回答增量同步”为准，行为不变。

| 场景 | 按钮行为与提示 |
| --- | --- |
| 有稳定新来源 | 可点击，与自动总结共用 LLM 流程，校验后直接更新 |
| 尚无可总结的对话 | 允许点击，原位提示“没有新对话可总结，请先完成一次回答”，不调用模型 |
| 主会话正在回答、有新来源 | 点击后排队，显示“将在当前回答结束后总结”；不停止主会话 |
| 正在生成 / 已排队 | 禁用并显示“正在总结” / “等待回答结束”，不重复建立任务 |
| 生成失败 | 保留错误并允许“重试总结”，与立即总结共用调度；不提供固定冷却等待 |
| Project 只读 / 来源不可恢复 | 禁用并显示对应原因 |


## 13. 检查面板：原生上下文

~~~text
原生上下文                      自动压缩已关闭
已用：32,000 / 128,000 Token     25%
剩余：96,000 Token
测量：原生指标 / 估算 / 暂不可用   更新时间
最近手动压缩：时间 / 尚无记录
[压缩原生上下文]
压缩会调用模型并消耗 Token，保留原生会话历史。
~~~

用量数值及比例配合低饱和进度条；比例超出容量时如实显示数值，图形可满格并标超限。接近容量（已知比例 ≥80%）显示提醒“可手动压缩以减少上下文占用”，达到或超出容量显示“上下文已满，请手动压缩后重新发送”；都不能自动执行。容量未知隐藏比例条并说明“模型容量未知”；无可靠用量显示“暂不可用”，不能显示空白或 0%。最后可信值显式标“上次测量”，运行中不伪装实时 Token 仪表。


压缩中 Composer 保留输入并提示暂不能发送；用户不需要重新打开会话。页面刷新或重新进入检查仅读取状态，不自动触发/重试压缩。检查不展示原生 transcript 路径、完整提示词、原始压缩摘要或秘密内容。

当前实现的模板创建/编辑随新建项目会话弹窗提供，独立 SessionMemory 模板库导航已接入。SessionMemory 支持指定连续来源范围重审，需在分支恢复验收中复验该入口。


记忆与检查采用相同的栏位间距、标题字号和细分隔线。摘要、目标、约束、事实、决策、下一步、产出分别展示，空栏位有明确文字；内容作用标记置于栏位内的辅助说明，不拼接在可展开标题上。“记忆 / 文件 / 检查”入口为三个分开的按钮，没有共享底色或连体外框。

“立即总结”禁用时通过按钮悬停说明原因：正在同步、先恢复会话或项目只读；编辑中则提示先保存或取消修改。不提供冷却倒计时，历史草稿不阻塞。

记忆局部修改弹窗中的富文本编辑区固定高 180px，超长内容在区内纵向滚动。已保存文本、列表及产出区域最高 160px，超过后在各自栏位内滚动，弹窗中的多条列表/产出控件区域最高 55vh，面板仍可整体滚动。取消请求不能撤销已完成的服务端事务；再次打开显示已保存事实，不用旧请求结果重新打开编辑或覆盖当前页面。

侧栏会话名称只使用当前记忆摘要，空白摘要回退为“新会话”，不使用 purpose、编号或历史草稿。摘要换行折为单行，长文本省略并可通过悬停查看完整名称；保存或 LLM 更新摘要后同步。

右侧面板高度限制在可视区域内，标题栏固定且不参与压缩；内容区占用剩余高度独立滚动。记忆、检查和文件内容区预留 8px 滚动条空间，使用浅灰绿轨道和清晰滑块，长内容不得从面板底部被裁切。

窄屏浮动右侧面板使用明确高度 `calc(100dvh - 24px)`（640px 以下减 16px），不依赖 auto 高度或内容撑开，关闭垂直居中定位。内容区占据标题栏之外的剩余空间；即使使用零 flex-basis，面板也不得缩为内容最小高度。

点击左侧会话时，关闭记忆/文件/检查面板、文件预览、记忆局部修改弹窗、项目资料弹窗、会话创建弹窗、SessionMemory 模板库和旧 SessionMemory 创建弹窗。未保存的记忆局部修改自动取消，不阻止会话切换。

项目行进入最近会话、直接点击会话记录，以及会话 ID 实际切换，均调用同一套关闭逻辑：关闭右侧面板及浮窗，不将已打开面板重置成检查视图。关闭的右侧面板从页面卸载；只有用户再次点击记忆、文件或检查才显示。

已有 SessionMemory 数据保留。应用启动不自动改写数据库，也不恢复旧实体或旧协议。

## 14. 检查中优先显示 Pi 上下文
检查内容顺序为“Pi 上下文 → Session → 运行环境 → 资源安全摘要”。Pi 区使用现有检查栏位样式，展示执行状态、已用/容量/剩余 Token、占比、采样时间、测量口径、最近压缩时间及“手动压缩”策略。状态与操作集中，按钮为刷新、压缩上下文；压缩运行时显示取消压缩，禁用不适用操作并给出原因。不显示任何原生上下文完整正文。

未启动显示“发送首条消息后可管理”，不可恢复显示恢复会话入口，取消显示“压缩已取消”，失败保留错误并允许用户重试。刷新失败标明未能取得最新状态，不将旧用量伪装当前。未知指标以文字呈现；占比已知时使用安全范围的进度条与实际数值。修改工作记忆继续在记忆面板，管理模型窗口和压缩集中在检查的 Pi 区。


## 15. 实时记忆同步与纠错展示
记忆作为与主对话并行的纠错线，标题栏的立即总结保留，正文顶部仅用简短状态行显示“与已完成对话同步 / 正在同步记忆 / N 条回答待同步 / 同步失败 / 来源不可用”，显示最近更新时间；不显示自动触发规则和回答计数说明。每次回答后后台更新直接写当前记忆，无需确认。

打开面板、主请求开始/结束和人工保存后立即刷新，全会话共享状态读取：同步中每 2 秒，已同步且面板可见每 30 秒，面板关闭且已同步时停止轮询，页面隐藏暂停，重新可见立即读取；摘要名称随写入同步，面板关闭时主会话仍读取安全同步摘要。富文本弹窗输入保持用户本地修改，不被轮询覆盖；冲突时保留输入并显示错误。人工修正立即更新指导线展示和后续独立总结，即使 LLM 同步尚未完成也不进入主请求。状态显示只保证跟随已完成来源，不把 LLM 更新耗时隐藏为“实时完成”。

工具调用和结果按 `03` 的节点与实时事件投影显示，完整内容可展开；失败明确标出，不由相邻 assistant 文本掩盖。


## 17. 独立项目 Agent 列表与编辑工作区

侧栏角色入口打开 Agent 列表弹窗。新增/修改进入独立编辑工作区，保留左侧导航，中间通过自然语言对话生成和修订，右侧只读展示已保存 Markdown、工作草稿与差异。执行流程见 `03`“独立项目 Agent 编辑”，字段见 `02`“独立项目 Agent Markdown”。

参考项目和文件明确标注“仅供生成/修订”，不建立目录授权或永久归属。主要、次要和危险按钮有明确外形；保存成功与取消均返回列表，失败保留草稿。引用中的定义只能归档；无引用时可确认删除。

独立 Session 的版本采用提示显示指导和能力差异；未采用时保留原版本，不能因列表刷新伪装为已升级。进入或退出编辑不清空主 Composer、不取消后台任务或改变原生历史。

会话删除（PSES-012）：独立项目会话行采用选择按钮和相邻删除按钮，不嵌套按钮；点击删除先确认，明确会话与专属记忆将移除、磁盘 Pi 历史保留，确认才调用 03 的 DELETE。等待时禁用重复提交；成功后刷新列表，当前会话被删除则回到所属项目，其他当前选择不改变；失败显示错误并保留条目。复用现有原生按钮及 lucide Trash2，不新增 UI 组件或审批流程。工作区投影见 06。

回复文件链接（PSES-013）：本地路径点击阻止浏览器导航，通过现有 GET /api/projects/:id/files/content?path= 打开右侧 FilePreviewPane，绝对路径限所属项目，相对路径从项目根目录解析；支持 #L行号、#L起始-L结束及 :行号，滚动并突出起始行。外部 HTTP(S) 不拦截，错误显示通知且保留会话。Workspace 对应 API 与映射规则由 06 WSP-016 定义。使用已有 FilePreviewPane，不新增组件。
