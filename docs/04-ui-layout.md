SCONN-001页面投影修正：会话区标题不显示“打开/关闭”文字和开闭操作按钮；连接状态只在会话检查中显示，连接错误沿用错误气泡与重试入口，选择会话时仍按既有API打开。用户主动关闭不自动重连。删除调用DELETE真正移除记录。回答/压缩作为活动反馈，不显示“已结束”生命周期；历史ended_at不限制重新使用。设置和对话打开后仅按事件刷新，不定时轮询；压缩终态之后的context_changed确保服务端解除互斥后读取最终许可。

选中会话时通过 `03` 的打开 API 建立或恢复对应 Pi Session，等待成功后展示其完整 Session Tree，标识活动分支；打开失败显示 API 错误和重试入口，不允许对未打开会话发送。切换立即展示新选择，不等待旧会话运行；再次打开旧会话时按 API 返回的运行状态和历史恢复展示，超时中止或状态未知时显示 API 返回的结果，不将其标记为成功。页面关闭、刷新或断线时的使用权和超时由 `03` 规定，页面不自行推断执行结果。

用户参考 `custom_message` 按 `03` 的确定父子关系归组时，显示在对应用户正文下方的“本轮附件”折叠区，保留完整原文、图片预览和原始节点；不再在正文前方重复占位。无法归组仍独立展示。参考消息实时阶段显示“本轮附件 · 同步中”，可靠关联后由原生节点接替，不在末尾残留 custom 的临时标头。

项目会话均按 `03` 将所属 Pi Session Tree 全部节点投影为对话流，按 API 返回的原生追加顺序展示，并通过父子关系标明分叉和活动路径；父节点缺失或自引用的节点标明异常、仍可查看，共享祖先只显示一次，不将不同分支伪装为连续上下文。内部节点、thinking、工具参数和完整结果、压缩、custom 及其他节点都可查看，不因敏感内容或原生 display 标记过滤；节点可折叠，但展开后保留完整内容。实时事件与历史节点的关联和重读以 `03` 为准；项目只读、发起与非发起页面均按 `03` 订阅所属 Session 的实时变化；首次打开和重连核对快照，不定时轮询历史。读取失败保留现有内容并显示错误。Assistant 回复使用安全 Markdown，支持加粗内的链接及链接文字内的行内代码等嵌套行内格式；原始 HTML 不执行，嵌套链接也需校验协议，链接文字不再生成嵌套锚点；安全渲染不删改正文。代码围栏和列表按原始 Markdown 展示，不将无标记的普通文字猜测为代码或列表。定向验证 tests/markdown-response.test.cjs 两项通过，覆盖 LCA 回复的加粗文件链接/行内代码、Go 围栏、列表，以及危险链接拒绝与 HTML 惰性展示；类型检查与差异检查通过，浏览器视觉未验收。


项目会话 Composer 的输入框下方紧邻并排提供“上传文件”和“参考项目文件”两个入口，已选文件、图片及折叠文本以内联不可编辑块插入输入区当前光标/选区位置，不在工具栏下方另列附件。打开上传或目录弹窗前保存选区，选择后插入该位置；无有效选区时回退输入区末尾。候选块为不可拆分的独立单位，块前后均提供可落点的编辑边界；左右方向键跨过整个块，Backspace/Delete 在边界删除整个块，选区替换同步移除对应发送材料。插入完成后光标自动落在最后一个新块后方，点击块本体也落在块后，移除按钮只删除该块；边界占位字符不进入草稿正文或消息 API。文件名不撑开输入区。发送后的用户消息不额外标注文件；Pi 树中的参考关联节点仍按会话树投影展示，PNG/JPEG/GIF/WebP 内容块支持折叠图片预览，完整原始图片节点仍可展开查看。上传打开系统文件选择器，不关联项目；参考打开视口居中的可关闭模态对话框，项目会话展示所属项目；逐级浏览目录、多选文件，不提供路径输入。“上传文件”和粘贴的非图片材料按PSES-025落盘供工具读取，图片继续直接识别；“参考项目文件”仅传位置供模型按需读取执行时最新内容，按钮提示说明这一区别。两类选择均可移除，随消息提交；接受前失败保留输入和选择并显示错误。项目会话无可用项目时禁用参考入口。

UI-040：项目和工作区会话统一使用带转圈的“正在等待”，替代原“正在思考”。直接投影所属会话事件派生的 running，在对话流所有历史与实时节点之后只显示一处；从运行开始持续到 complete、agent_settled、已确认失败或空闲状态使 running=false，文本、thinking、工具调用、工具结果及节点同步不提前隐藏。中止请求发出后仍等待真实终结；历史快照替换实时节点时不闪断或重复显示。该提示只表示本轮执行仍在进行，不代表模型实际 thinking，不进入 transcript、不新增计时器、轮询、API或持久状态。

PSES-027：Composer整个输入区域支持从本机拖入一个或多个文件/图片，复用上传的内联附件与所属messages API references，不自动发送。只拦截文件拖放，防止浏览器打开文件；普通文本拖放保留原行为。拖入文件保留原名与字节，与已选上传/项目参考共用10项和上传字节额度；超限、目录或无法读取的文件整批拒绝并提示，原输入与附件不变。运行/提交/阻塞时不接收文件且阻止浏览器打开；接受前发送失败仍保留材料。拖入属于上传，非图片按PSES-025存储，服务器项目参考继续只传位置，不复制原件；不新增模型或API。附件插入沿用输入区已保存选区，无有效选区时在末尾插入。

Composer 支持粘贴图片为可移除的缩略图附件，也支持粘贴普通文件或混合图片/文件，全部沿用上传文件的内联块与 references 校验；保留原文件名及字节，读取失败用现有错误气泡提示；超过 10 行或 1000 字符的粘贴文本不铺开，只显示“已粘贴 N 行”及移除按钮。其他文本沿用原生粘贴；粘贴材料与上传文件共同计数并受同一限制，失败用气泡提示并保留原输入。仅附件也允许发送，完整内容沿用 references 契约进入所属 Pi。

Composer 支持 Enter 发送、Shift+Enter 换行；发送按钮仍可直接提交。IME 候选组合期间按 Enter 只确认候选、不提交；判断同时使用 composition 事件状态、`nativeEvent.isComposing` 和旧浏览器 `keyCode=229` 兼容标记。运行时发送/停止处于同一操作组。项目 Session 在排队、启动和运行阶段均可停止；提交停止后显示“正在停止”，保持执行门禁直到 Runtime 确认结束。结果 unknown 时不提供会伪装取消的停止按钮，显示待核对状态和准确恢复入口。Composer 不提供模型、Runtime、工具、Agent、MCP 或 Skill 的配置控件。

### 紧凑 Tailwind 对话流

会话主体用 Tailwind `px-3 py-3 sm:px-4`，tree 节点之间固定间距 `gap-1`（4px），普通节点不额外设置纵向 padding；消息内部 thinking、工具调用与正文块也统一使用 4px 间距，折叠展开区仅顶部留 4px、底部不加 padding，用户消息 `px-3 py-2`，assistant 正文不套多层厚卡片。消息身份和正文间距 `gap-1`；不设消息最小高度，短消息自然撑开，正文使用可用宽度。Markdown 段落、标题和列表保持紧凑间距与可读行高。标题栏采用 `px-3 py-3 sm:px-4` 且不设最小高度，Composer 外层 `px-3 py-2 sm:px-4`；输入正文占满宽度，`px-3 py-2`、初始及最小高度 112px，可纵向拖动至视口高度的 40%（上限不低于 112px）。上传、参考文件与发送/停止合并为同一紧凑底栏，快捷键提示以底栏小字常驻展示，与工具、发送按钮共用一行，不单独增加提示栏高度；运行及禁用原因在同一位置替换快捷键提示。附件以内联块出现在输入区，不设独立附件行或下方 padding；工具入口、提示及发送操作仍共用紧凑底栏。会话连接、发送及上传校验的报错使用右下角气泡通知，不占用输入框或对话流空间；气泡完整展示错误、允许手动关闭，有既定重试动作时保留重试按钮，不自动消失或改变执行状态。文件浏览弹窗内的读取错误仍在弹窗内展示。底部操作行不设固定最小高度。正文显示文字和安全 Markdown，thinking、工具调用及结果就地展开；不展示额外的“节点信息”组件、角色标头或详情入口。消息正文直接展示；model_change 等非消息节点仅使用原有“原生节点 · 类型”折叠面板，展开显示完整原始 entry。原生节点、thinking、工具调用和完整工具结果共用同一折叠样式：折叠标题为 10px 灰色文字，无边框、底色或卡片 padding，展开内容仅顶部留 4px 间距、底部不加 padding；thinking 与原始参数/节点使用紧凑 10px 行高 16px，原始内容无额外背景和 padding，完整工具结果展开后同样使用通用 Raw 展示完整消息对象，采用 10px 等宽灰字、16px 行高，无底色或额外 padding，不再套用正文 Markdown 排版。实时工具与事件也复用该样式。节点身份与父子关系保留在原始内容中。未知块、内部节点和异常节点仍可查看，不以 JSON 代替普通对话正文。分支信息用轻量标记表达，全树按原生追加顺序展示，共享节点只展示一次。订阅连接的等待、断线和错误独立于运行成功/失败；页面收到服务器 ping 后应答，不自行定时保活。

## 5. 会话辅助入口与弹窗

当前会话只提供“文件”和“会话检查”两个独立按钮；会话检查内部为“会话树”和“会话设置”两个页签。SessionMemory 的模型、API、模板和后台总结均退役，不在会话、创建或导航中提供入口。侧栏按SLIST-001显示API返回的最新用户输入预览与最后打开时间，无用户输入时显示新会话，不触发模型生成名称。

文件与会话检查使用非模态浮动窗口，互斥显示；打开一个关闭另一个。窗口固定在视口右上方，不显示全屏遮罩，不锁背景滚动，不捕获焦点或阻止主会话输入/发送和左侧点击；不挤压对话宽度。会话检查高度以Session设置内容的自然高度为准，会话树使用相同高度；不再按70dvh或720px缩短设置。设置区域保持布局占位，树页覆盖同一内容区域，切页签不改变窗口高度。窗口最多占视口减顶部与底部边距，超出时仅当前页签内容滚动，外层不再叠加滚动条。标题栏和页签保持可见，仅页签内容独立滚动。窄屏限制宽高并保留视口边距。支持关闭按钮与Esc；关闭时仅当焦点仍在窗口内才恢复到打开入口，不抢走用户已经移到Composer的焦点。所有节点、页签及操作可用键盘访问。

会话检查页签采用明确的标签栏：选中项使用浅绿色底、深绿色文字、加粗及底部指示线，未选项使用浅灰常规字重、透明背景，悬停只略加深文字，不添加底色；两项等宽，复用现有SessionInspection。使用tablist/tab/tabpanel语义与aria-selected关联，左右方向键、Home/End切换并移动焦点，Tab进入当前内容。页签切换保持窗口高度。

## 6. 会话树：标题与正文定位

数据来自 03 的 messages 全树 API，复用当前会话快照和订阅。全部分支按 parentId 缩进、同级按原生追加顺序排列，共享祖先只展示一次；异常节点保留并标明，读取失败保留现有树及重试入口，未初始化与读取失败不能都显示成空树。

会话树样式对齐Pi TUI tree-selector：等宽紧凑单行、无卡片间距；单子节点链保持平齐，分叉使用三字符缩进和├─/└─/│连线，分叉后的首代保留分组缩进。选中行使用›、柔和底色与加粗，活动路径全部祖先使用•，当前叶子通过可访问名称区分；标签使用[label]强调色，后接user:/assistant:首行标题预览、[toolName]、[model: id]、[thinking: level]等原生类型摘要。节点ID不常驻占行，可在悬停提示和正文原始节点查看；底部显示选择序号/总数。标题本地确定性生成，不调用模型、不持久化，不展开完整正文、thinking、参数或结果。单行省略只影响预览，中间完整对话和导出保持原文可查。复用现有SessionTreeNavigator，不新增组件；保留全部节点与原有同级追加顺序，不照搬TUI默认过滤或活动分支排序。

活动标记来自 activeLeafId；浏览选择初始为活动节点，后续选择保存在当前 Session 的客户端状态中，切换 Session 时清除。点击节点标题记录该节点、关闭弹窗，再在中间会话定位到相同 entryId；展开定位所需折叠祖先或附件归组区域并短暂高亮目标。重新打开会话检查可查看选中节点并进入设置。定位失效时说明节点不可用并刷新快照，不跳到相似正文。点击标题不调用 Pi navigateTree/branch，不改变活动分支或下一次对话上下文。

Pi TUI样式定向验证：tests/session-tree-presentation.test.cjs验证单链平齐、分叉连线、活动路径/浏览选择分离、类型摘要、label、异常关系保留及节点顺序；tests/session-auxiliary-dialog.test.cjs复验弹窗和定位交互，两文件2项通过。辅助窗口后续调整为非模态、统一固定高度；同一交互测试补充背景输入/操作、页签尺寸不变、项目/工作区左侧空白点击关闭与切换关闭验证。未进行真实浏览器视觉验收。

## 7. 会话设置

两类会话复用SessionInspection中的设置内容容器，统一p-5、text-sm、space-y-5及分区标题、分隔线、按钮样式；均先显示Session名称、ID及连接状态，再显示共享模型和上下文区域。工作区的核对请求使用与项目待核对操作相同的分区样式，范围独有的API动作仍只按各自契约显示。会话检查入口复用main-toolbar的辅助工具按钮样式。

所有动作及许可来自 03 §10～15 的 model/fork/export/context/compact/restore/recover API；设置不编辑 models.json 或 settings.json，不提供参数覆盖输入框。模型列表中的容量字段只是读取投影，不能限制服务端对完整 Pi 参数的支持。

## 8. 文件弹窗

文件浏览与文件预览属于同一个非模态浮动窗口。宽屏内部为目录树与预览两区，窄屏在弹窗内切换浏览/预览，不打开第二个抽屉或单独的预览列。文件树来自所属范围的文件列表 API，非 Git 仓库也能浏览；Git 状态为可选附加信息，失败不遮蔽文件列表。项目根目录按钮、根路径与子目录路径保留，长路径可横向滚动。

本地源码链接调用所属 API 后打开该弹窗，自动选择文件并滚动、高亮目标行；项目路径边界与工作区项目定位见各自 API。预览只读，代码使用浅灰绿底与深灰字。空目录、加载、读取失败、目录截断、二进制和超限均明确展示。敏感路径、越界、符号链接和大小校验仍由服务端完成。外部链接保持原行为，选择变化后的旧响应不能覆盖新文件。

## 9. 左侧动作与会话切换

左侧整个区域的任何单击（包括空白、文字及按钮）的动作开始前，统一关闭现有文件、会话检查及其附属浮层，也关闭已有项目资料、会话创建等临时弹窗，再执行目标动作；目标动作需要弹窗时打开它自己的新弹窗。覆盖展开/收起、项目/工作区选择、新建、删除、角色/MCP/设置及导航收缩；点击当前已选会话也执行关闭。实际会话身份变化（含其他入口与程序化导航）同样触发，不能只监听某一个会话行按钮。

关闭统一清理未提交表单草稿、取消本地读取或忽略迟到响应，不让旧请求重新打开弹窗或覆盖新会话。同一 Session 的树浏览选择保留，供定位后重新打开设置并从该节点创建会话；树正文定位可在关闭后完成，左侧导航或会话切换时清除该目标与选择。已接受的模型切换、压缩和创建不因关闭而取消；停止与取消压缩必须调用对应 API。未提交的设置选择丢弃，主 Composer 草稿及主请求生命周期按原契约处理。

通用动作按 03 §11～15 的完整契约投影，状态与验收计划见05 §15；GAP-006及工作区专属缺项本轮保留。没有 Session 时会话检查禁用并给出原因；没有可浏览项目时文件入口按所属 API 能力禁用。两种会话同步采用以上投影，工作区专属映射见 06。本轮状态见 05，文档完成不代表弹窗、模型切换、派生和导出已经实现。

## 10. 独立项目 Agent 列表与编辑工作区

侧栏角色入口打开 Agent 列表弹窗。新增/修改进入独立编辑工作区，保留左侧导航，中间通过自然语言对话生成和修订，右侧只读展示已保存 Markdown、工作草稿与差异。执行流程见 `03`“独立项目 Agent 编辑”，字段见 `02`“独立项目 Agent Markdown”。

参考项目和文件明确标注“仅供生成/修订”，不建立目录授权或永久归属。主要、次要和危险按钮有明确外形；保存成功与取消均返回列表，失败保留草稿。引用中的定义只能归档；无引用时可确认删除。

独立 Session 的版本采用提示显示指导和能力差异；未采用时保留原版本，不能因列表刷新伪装为已升级。进入或退出编辑不清空主 Composer、不取消后台任务或改变原生历史。

会话删除（PSES-012）：独立项目会话行采用选择按钮和相邻删除按钮，不嵌套按钮；点击删除先确认，明确会话将移除、磁盘 Pi 历史保留，确认才调用 03 的 DELETE。等待时禁用重复提交；成功后刷新列表，当前会话被删除则回到所属项目，其他当前选择不改变；失败显示错误并保留条目。复用现有原生按钮及 lucide Trash2，不新增 UI 组件或审批流程。工作区投影见 06。

回复文件链接（PSES-013）：本地路径点击阻止浏览器导航，通过现有 GET /api/projects/:id/files/content?path= 打开非模态文件浮窗并复用 FilePreviewPane，绝对路径限所属项目，相对路径从项目根目录解析；支持 #L行号、#L起始-L结束及 :行号，滚动并突出起始行。外部 HTTP(S) 不拦截，错误显示通知且保留会话。Workspace 对应 API 与映射规则由 06 WSP-016 定义。复用现有文件读取与预览组件，容器按文件弹窗规则装配；旧预览位置的验证不替代新弹窗验收。

SEARCH-002：共享输入框附件行只保留一个原生select选择器（aria-label=联网搜索），选项为“内置搜索 · 服务端”“工具搜索 · 应用端”“无搜索”，默认内置搜索。控件使用24px紧凑高度、单层细边框和11px常规字重，无文字/控件阴影；地球图标与下拉箭头置于同一边框内，原生select关闭系统外观并预留图标空间。依次映射消息API的(webSearch,toolSearch)=(true,false)/(false,true)/(false,false)，页面不同时开启两种方式；切换会话恢复默认，忙碌/阻塞时禁用。用户选定搜索方式后自动聚焦Composer并恢复原光标/选区，不改变草稿或触发发送。提示内置搜索由OpenAI服务端执行，工具搜索通过部署主机网络直接访问Bing与目标网页，不需要搜索Key；代理配置错误显示API错误并保留草稿，不默默切换。搜索结果/正文/来源/失败投影原生工具历史。
